# Student Performance Analytics

## Project Overview

This project analyzes student performance using MySQL, Python, Pandas, and Matplotlib.

The goal is to understand student marks, attendance, course-wise performance, and city-wise performance.

## Technologies Used

- MySQL
- Python
- Pandas
- Matplotlib

## Dataset

The dataset contains student information such as:

- Student ID
- Name
- Age
- Gender
- City
- Course
- Marks
- Attendance

## Analysis Performed

- Total number of students
- Average marks
- Average attendance
- Highest and lowest marks
- Top 5 students
- Course-wise performance
- City-wise performance
- High-performing students
- Attendance vs marks analysis

## Visualizations

- Average Marks by Course
- Average Marks by City
- Marks Distribution
- Attendance vs Marks

## Key Insights

The analysis helps identify patterns in student performance based on courses, cities, marks, and attendance.
